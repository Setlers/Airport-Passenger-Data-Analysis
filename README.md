# Airport Passenger Analysis

Python data analysis of passenger traffic at M. R. Štefánik Airport from 2008 to 2022.

## Technologies

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Analysis

The project analyzes:

* regular and irregular passenger traffic
* total passenger numbers
* year-over-year changes
* percentage changes
* highest and lowest passenger traffic
* largest increases and decreases

## Key Results

* **Highest passenger traffic:** 2018
* **Lowest passenger traffic:** 2020
* **Largest decrease:** 2020
* **Largest increase:** 2022

The analyzed data is exported to CSV for further visualization in **Power BI**.
